# らいふ スタンプカード

町外れのお好み焼き屋向けのデジタルスタンプカードMVPです。

## できること

- お客さん登録
- スマホ向けスタンプカード表示
- 10個で満タンのスタンプ表示
- 特典表示: お好み焼き1枚トッピング無料
- お店からの一言メッセージ
- LINE登録ボタン
- 店側管理画面でお客さん検索
- スタンプの追加・減算
- 来店回数と最終来店日の確認
- 10個たまったお客さんの確認

## 画面

- `/` トップ画面
- `/register` お客さん登録画面
- `/card?id=ユーザーID` お客さんのスタンプカード画面
- `/admin` 店側の管理画面

## データ保存

MVPではブラウザの `localStorage` に保存しています。

保存するデータ:

- ユーザーID
- 名前
- スタンプ数
- 来店回数
- 最終来店日
- 特典利用済みかどうか

保存処理は `lib/customerRepository.ts` にまとめているため、あとからSupabaseへ差し替えやすい構成です。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで開く:

```text
http://localhost:3000
```

## 確認手順

1. トップ画面から「お客さん登録」を開く
2. 名前を入力してスタンプカードを作る
3. `/admin` を開く
4. 登録したお客さんに「スタンプ +1」を押す
5. カード画面でスタンプが増えていることを確認する
6. 10個まで増やし、「特典が使えます」が表示されることを確認する
